  • 不能拼 releases/latest/download/Cicada-<v>-…：发版只带有改动的平台，只发 Linux 的版本不是 latest，直链会 404。
  • scripts/site.py 构建时按平台找“最新一个带这个平台文件的 release”，链到那个 release 的确切文件，文件大小也从 API 读，不手写。
  • Windows 直接用 releases/latest/download/Cicada-Setup.exe / Cicada-Setup-arm64.exe：文件名不带版本号。latest 只在带 Mac 包时移动，所以 Windows 也要走上一条的查找，或确保每次 Windows 发版都带 Mac。
  • 新 release 先是草稿：scripts/deploy-site.sh 要在 scripts/publish-release.sh 之后跑，否则链到看不见的草稿。

三步开始使用

按你的手机看

Android 各家、各版本拦的地方不一样。选一下，只看你会遇到的。

Android 版本
不确定？设置 › 关于手机 › Android 版本
品牌
浏览器给出机型时会自动预选

    知了的引导会自己判断，带你走对应的这几步。

    安装时
    提示不能安装未知应用

    点提示里的“设置”，给下载它的那个 app（浏览器、微信）打开“允许安装”，返回继续。

    各家叫法和位置不一样，跟着系统提示走。

    第一次打开
    麦克风和通知

    麦克风：听手机里的声音和面对面，系统都要求开。

    每次开始听
    系统问要不要录屏

    Android 只能借录屏的授权读手机里的声音。点“开始”，知了只取声音，不录画面。

    每次开始听都会问一次；按钮的叫法各家不同。

    开会时
    微信通话、腾讯会议、Zoom 没字幕

    这些 app 的声音系统不让录。开外放，在知了里改选“面对面”，用麦克风听。

    20 秒没听到声音时，知了也会这样提醒。

    简体中文 · English

    无论是用 Zoom、飞书、腾讯会议开会，还是听 X Spaces 和 YouTube 直播，知了都能实时给出双语字幕、边听边写结构化纪要。遇到需要发言的时候，按住说话键开口，对方就能在会里直接听到翻译好的语音。

    隐私与权限 改

    声音采集、语言识别、语音识别和会议录音在 Mac 上全部在本机完成。……

    Windows、Linux、Android 版用 Ming 识别：说话的声音分段发给 Ling 的服务，识别和翻译一次完成，所以必须填 Ling key。

    系统要求与安装 改

    Mac

    需要 macOS 14.4 或更新版本、Apple 芯片的 Mac。下载 Cicada-<版本>-macOS-AppleSilicon.dmg，打开后把知了拖进应用程序文件夹；第一次打开被拦下时，去系统设置的隐私与安全性里点仍要打开。

    Windows 已改

    下载 Cicada-Setup.exe（骁龙笔记本选 Cicada-Setup-arm64.exe），双击安装，不用管理员权限；SmartScreen 拦下时点更多信息 › 仍要运行。以后的新版本在知了里提示，点一下就升级。

    Linux

    tar xzf Cicada-<版本>-Linux.tar.gz && cicada-linux/install.sh

    Android

    在手机上打开 Cicada-<版本>-Android.apk，允许安装未知应用。

    每个文件都能用 Releases 页面里的 checksums.txt 核对 SHA-256。
