# 知了 支持 macOS 14 / 15 技术方案

状态：已实现并验证（2026-11-04）。最低系统 14.4；在 macOS 26 本机和 macOS 14.5 虚拟机里都跑过主流程。

## 和 Windows / Android 的区别

Windows、Android 是另起的代码库，只共享规格。低版本 macOS **是同一个 app、同一个二进制**：`Package.swift` 和 `Info.plist` 的最低系统是 14.4，运行时按系统选识别引擎。26 上的行为不变。

## 差多少（实测）

把平台改成 14.2 / 15.0 编译，报出的“只在新系统可用”：

| API | 最低系统 | 处理 |
|---|---|---|
| `SpeechAnalyzer`、`SpeechTranscriber`、`AnalyzerInput`、`AssetInventory` | 26 | 收进 `Recognition.swift`，引擎只用它 |
| `TranslationSession(installedSource:target:)` | 26 | 离线翻译兜底只在 26；14 / 15 用 Ling → Google |
| `onScrollGeometryChange`、`pointerStyle` | 15 | `Compat.swift`：14 上纪要跟随不感知手动上翻，链接光标用 `NSCursor` |
| `AVAudioFile.close()` | 15 | 测试里改成出作用域关闭 |
| Core Audio process tap | 14.2 | 不动；下限定 14.4（“录制系统声音”权限从 14.4 起是独立的一项） |

## 实现

- `Recognition.swift`：`Recognition.start / transcribe / status / install / format / startNow`，协议 `RecognitionStream`。
  - 26：`Analyzer`，包住 `SpeechAnalyzer`，行为和原来一样。
  - 14.4–15：`LegacyStream`，用 `SFSpeechRecognizer`（`requiresOnDeviceRecognition`，声音不出电脑）。它没有“句子”：一句一个任务，停顿 0.7 秒或 `finalize` 时结束，满 45 秒强制结束。
  - `DeferredStream`：按住说话键时麦克风先开，识别器准备好再把缓存的声音交过去。
- `AudioRouter.attach(stream)` 喂 `RecognitionStream`；`ListenEngine`、`SpeakEngine`、`LanguageDetector`、`VirtualMic`、`SpeakTest`、`FileImport` 都改用它。导入文件在 26 上仍用 `SpeechAnalyzer(inputAudioFile:)`，旧系统按行喂给 `LegacyStream`，再按句号拆句、按字数估时间。
- 开发版 `lsctl recognizer:legacy` 或 `open --env CICADA_RECOGNIZER=legacy`：在 26 上跑旧引擎。

## 实测发现

1. **旧识别器要打开“听写”**（系统设置 › 键盘 › 听写，`com.apple.assistant.support` 的 `Dictation Enabled`）。关着时每个任务立刻失败（`kLSRErrorDomain` 201）。语言要加进听写语言才有本机模型（`supportsOnDeviceRecognition`）。引导第一步在旧系统上多一行“识别语音”，按钮先请求“语音识别”权限，再打开键盘设置；状态栏和面板提示“请在系统设置 › 键盘里打开“听写””或“……听写里添加 X”。
2. **两个识别任务不能同时跑**：同时跑时两边都回“No speech detected”（1110）。所以：上一句的结果回来前，下一句的声音先攒着（最多 6 秒）；语言检测的短片段等实时那句结束后才跑（最多等 4 秒，等不到就跳过这次），跑的时候实时这边也先攒着。
3. **输出设备自带麦克风时读错声道**（与系统版本无关）：聚合设备的输入是“输出设备自己的输入声道 + tap”，原来固定读前两个声道。输出设备有麦克风（虚拟机的声卡、USB 耳机）时读到的是麦克风。`SystemAudioTap` 现在用 `kAudioOutputUnitProperty_ChannelMap` 跳过这些声道。也因为聚合里有这个设备，这类设备上开始听会先弹“麦克风”权限。
4. 慢的 Mac（虚拟机没有神经引擎）一句话的结果可能比这句话还长才回来：兜底关句的超时是 10 秒 + 2 倍句长。
5. 权限顺序（14.5，首次开始听）：麦克风（仅当输出设备带麦克风）→ 录制系统声音 → 语音识别。
6. 小屏幕（1024×768）：菜单栏面板高约 700 点，放不下时顶部被推出屏幕。现在超过屏幕可用高度就在面板里滚动。主窗口、设置、引导、试一句都放得下。
7. 自动更新：以后的版本如果提高最低系统，旧 Mac 会装上打不开的版本。`Updater` 现在先看新版本的 `LSMinimumSystemVersion`，不满足就提示“新版本需要 macOS X 或更新版本”，不替换。
8. 文案：14 / 15 没有本机翻译，AI 服务页的“不行时换 Google、本机”在旧系统上去掉“本机”；“听到”菜单里没装的语言写“要先加进系统的听写语言”，而不是“选中后自动下载”。
10. **开会时按住说话键**（以及“会议室”模式，两边都用麦克风）：两个实时识别同时跑会互相打断，会议那边只剩空句，你说的只剩最后几个词。旧系统上按住说话键时识别归你：会议那句当场结束，会议声音最多攒 6 秒，松开后接着识别（攒的全是静音就丢掉，时间戳不会提前）。26 上两边照旧同时跑。
11. **Mac 自带声音念译文卡住**：14.5 上 `AVSpeechSynthesizer.write` 给完所有音频后不发结尾的空缓冲（26 上会发），没有 Ling key 时的同声传译、“试一句”、虚拟麦克风试音都一直卡在“正在播放”。现在以结尾缓冲或代理的 didFinish 先到者为准（`SpeechWriter`）。虚拟麦克风（BlackHole）在虚拟机里能装：下载、校验 SHA-256、输管理员密码、加载、切换系统麦克风、试音都通过。
12. **拒绝过“录制系统声音”**：拒绝后 tap 照样能开，只是全是静音，引导却显示“已打开”。现在用 TCC 自己的预检（运行时加载，取不到就按原来的办法）判断：被拒时引导显示“去开启”和“重新打开”，状态栏提示去系统设置允许后重新打开知了。14 上这个开关在“屏幕与系统录音 › 仅系统录音”里；打开后要重开 app 才生效（系统自己也这么提示），从引导里重开不会跳过引导。
13. **首次打开（未公证）**：14 的拦截框是“来自身份不明的开发者”，只有“好”一个按钮；隐私与安全性里点“仍要打开”、输密码后还要再点一次“打开”。DMG 里第一步改成“点完成或好”，第三步改成“按提示输密码确认”。DMG 窗口、拖拽安装、正式版首次运行在 14.5 上都正常。
14. 在 14.5 上查过、没问题的：6 个系统设置跳转都到对的页面；纪要窗口默认不出现在截屏里，打开“共享屏幕时让对方看到”后出现；登录项能开。
15. **开会时导入文件**：两边抢一个识别器，导入的文件 0 句，会议的句子也被截断。旧系统上导入让着会议：会议有句子在识别或要开始时，文件这句先收尾，等会议停顿再继续。会议和文件都完整，只是导入变慢（10 秒的文件在会议里约 45 秒）。
16. **说话人识别**：在 14.5 上能用（声纹模型首次使用时编译、两人各 6 句标成说话人 1 / 2）。但旧识别器常常不加句号，“被停顿切开的半句接回去”的规则会把两个人的话接成一行。旧系统上每行本来就在真停顿处结束，现在只接知了自己切开的长句。修后 12 句全部分开、说话人都对。
17. **只有一种听写语言**：旧系统上一种语言没法比较，也没法替用户补装第二种；原来的“单模型校验”每次都抢走识别器，还会弹“听不出是哪种语言”。现在旧系统上只有一种听写语言时，直接按这种语言记录，不弹窗。检测片段也改成一个一个跑，最多等 15 秒。
18. **14 上纪要窗口往上翻**：用几何位置代替 15 才有的滚动回调。往上翻后不再被拉回底部，显示“N 条新内容”，和 26 一样。
19. **中文听写模型在虚拟机里下不来**：在听写里加了普通话，系统一直没有开始下载（有无代理都一样，日志里也没有下载记录），所以中文识别没测到，要真机。提示改成“请在系统设置 › 键盘 › 听写里添加中文，下载好后可用”，刚加上、还在下载的人不会以为没加成功。
9. 用到的 52 个 SF Symbols 在 14.5 上都存在（逐个在虚拟机里查过），不会显示成空白。

## 验证

- 单元测试 82 个通过（新增旧引擎拆句测试）。
- macOS 26 本机：26 引擎和 `recognizer:legacy` 都跑过；26 引擎回归正常。
- macOS 14.5 虚拟机（tart，`ghcr.io/cirruslabs/macos-sonoma-vanilla:14.4.1`，实际是 14.5）：首次权限、引导、示例会议、实时字幕和翻译（Ling）、合并断句、实时纪要、会议记录、导入文件、按住说话（文件模拟）、中英文界面。截图在 `~/Downloads/cicada-macos14-test/`。
- 需要真人和真机：真 Mac 上 14.4 / 15 的权限对话框、外接带麦克风的耳机、中文听写模型的识别质量、长会议。

## 已知限制

- 旧系统只能识别加进“听写”的语言；自动识别要至少两种听写语言。
- 选了没加进听写的语言时会退回原来的语言，提示只闪一下（状态随后变回“正在听”）。
- 14 上纪要窗口里往上翻时，新句子仍会把视图拉到底部。
- 没有离线翻译（14 / 15）；没有 Intel 版本。
